# 飲料店點餐 Web 應用計畫

## 願景

製作一個容易上手、互動完整的飲料店點餐 Web 應用。使用者可以挑選飲料、設定甜度與配料、將品項加入購物車，並查看訂單明細和總價。作品要有足夠的功能與完成度，適合作為課堂作業展示，同時把範圍控制在可於合理時間內完成，不延伸到需要數小時的大型系統。

## 範圍與初步方向

- 形式：單頁 Web 應用，使用原生 HTML、CSS、JavaScript，無需安裝套件。
- 核心流程：選飲料與客製選項 → 加入購物車 → 檢視訂單 → 計算總價 → 確認點單。
- 已實作：六款飲品、三種分類、甜度／冰塊／杯型／配料、購物車品項合併與數量管理、總價及結帳摘要、窄螢幕樣式。
- 暫不納入：登入、真正付款、後端、資料庫等超出課堂作品初版所需的功能。
- 技術與評分要求仍需向課程核對；目前採用推薦方案先做可操作版本。詳見 [decision.md](decision.md)。
