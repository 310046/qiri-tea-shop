# 沏日點餐作品展示講解稿

> 通用版展示流程，約 2–3 分鐘；取得課程評分規準後，請依必備項目調整順序與時間。

## 開場（約 20 秒）

這是「沏日」飲料店點餐單頁，使用原生 HTML、CSS 和 JavaScript，不需安裝套件或啟動伺服器。展示範圍是從挑飲料、設定客製選項到確認模擬訂單；沒有實際付款或後端服務。

## 操作展示（約 90 秒）

1. 由首頁進入今日菜單，展示分類與搜尋。可輸入「柚子」查看風味搜尋，也可點選奶茶分類。
2. 選一杯飲品，調整甜度、冰塊、杯型與配料，加入購物車；展示杯型／配料加價後的小計。
3. 再加入相同客製品項，說明購物車會合併數量；用加減或移除按鈕修改訂單。
4. 重新載入頁面，展示未結帳購物車會保留。確認模擬點單後，購物車清空，最近完成訂單留下時間、品項與總額。
5. 點「再點一次」，展示原客製與數量回到購物車；如果相同客製品項已在購物車，也會合併數量。

## 設計說明（約 30 秒）

- 飲品資料集中在 JavaScript 陣列，再依分類產生菜單，方便維護品項。
- 客製選項組成品項識別鍵，確保只有完全相同的飲品和客製才會合併。
- 購物車與最近五筆訂單用瀏覽器 localStorage 保存，所以只在同一瀏覽器可見；這是展示用模擬資料，不是正式交易紀錄。
- Node.js 內建測試驗證搜尋、計價、購物車保存、結帳與重新點單流程。
